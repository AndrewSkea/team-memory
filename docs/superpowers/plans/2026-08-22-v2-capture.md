# team-memory v2 — Capture, Review and Publish Implementation Plan (Plan 3 of 5)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the loop — a coding session ends, candidate memories are extracted locally, secrets are stripped before anything is written, a human approves or rejects them, and only approved memories reach the shared repository.

**Architecture:** Harness hooks call `team-memory hook <event>` with a JSON payload on stdin. The hook command is a thin client: it starts the daemon if needed, posts the payload, and exits fast — a slow hook is a hook users disable. Extraction runs inside the daemon, asynchronously, by shelling out to the user's already-authenticated local agent (`claude -p` or `codex exec`), so team-memory never holds an API key and never makes an LLM call of its own. Everything extracted lands in staging. A review API exposes the queue to the UI, and approval is the only code path in the system that writes to the git repository or pushes.

**Tech Stack:** Go 1.26.2. `github.com/zricethezav/gitleaks/v8` as a library. `os/exec` for the local agent. go-git for push. Everything from Plans 1 and 2.

**Spec:** `docs/superpowers/specs/2026-08-22-team-memory-v2-design.md` — implements §6 (Capture and review) and §7 (Harness integration). Read the spec alongside this plan.

## Global Constraints

- Module `github.com/AndrewSkea/team-memory/mcp`. `CGO_ENABLED=0` for every build and test.
- **A hook must never block a user's session.** `team-memory hook` has a hard 2-second budget and exits 0 on every failure path. Exit 2 is reserved for the one case the harness contract defines as blocking, which team-memory never uses.
- **Nothing reaches the repository without an explicit human approval call.** Extraction writes to staging only. `store.Put` is reachable from exactly one handler, `approve`.
- **gitleaks runs before staging, not before approval.** A secret that reaches disk in staging has already leaked to a place the user did not choose. Redact at the earliest write.
- No API key is ever read, stored, or forwarded. Extraction shells out to the user's own authenticated CLI. If neither CLI is present, extraction is skipped with a clear message — never replaced by a direct API call.
- Push is fast-forward only and to the configured branch only. Never force-push, never `gc`, never rewrite history.
- All outbound HTTP goes through `netguard.Client()` (Plan 2 Task 1).
- Tests use `t.TempDir()`. No test invokes a real `claude` or `codex` binary; the agent runner is an interface with a fake in tests. No test reaches the network.
- Run tests with `cd mcp && CGO_ENABLED=0 go test ./...`.

```go
// Package hookio implements team-memory's side of the harness hook contract.
//
// Claude Code, Codex and the other CLI harnesses converged on the same shape:
// a JSON object on stdin naming the session, its transcript, the working
// directory and the event. Unknown fields are ignored so a harness adding one
// does not break us.
package hookio

import (
	"encoding/json"
	"errors"
	"fmt"
	"io"
	"time"
)

// Budget is the wall-clock limit for one hook invocation. A hook that makes a
// user wait is a hook the user turns off.
const Budget = 2 * time.Second

// Payload is the hook event as the harness sends it.
type Payload struct {
	SessionID      string `json:"session_id"`
	TranscriptPath string `json:"transcript_path,omitempty"`
	CWD            string `json:"cwd,omitempty"`
	HookEventName  string `json:"hook_event_name,omitempty"`

	// Harness names the CLI that fired the hook. It is set by the install
	// command, not by the harness, so we can adapt transcript parsing.
	Harness string `json:"harness,omitempty"`
}

// ErrNoSessionID is returned when a payload cannot be attributed.
var ErrNoSessionID = errors.New("hookio: payload has no session_id")

// ParsePayload decodes a hook payload from stdin.
func ParsePayload(r io.Reader) (Payload, error) {
	data, err := io.ReadAll(io.LimitReader(r, 1<<20))
	if err != nil {
		return Payload{}, fmt.Errorf("hookio: read payload: %w", err)
	}
	if len(data) == 0 {
		return Payload{}, errors.New("hookio: empty payload on stdin")
	}
	var p Payload
	if err := json.Unmarshal(data, &p); err != nil {
		return Payload{}, fmt.Errorf("hookio: decode payload: %w", err)
	}
	if p.SessionID == "" {
		return Payload{}, ErrNoSessionID
	}
	return p, nil
}
```

Create `mcp/hookio/client.go`:

```go
package hookio

import (
	"bytes"
	"context"
	"encoding/json"
	"fmt"
	"net/http"
	"time"

	"github.com/AndrewSkea/team-memory/mcp/daemon"
	"github.com/AndrewSkea/team-memory/mcp/paths"
)

// Deliver posts a hook payload to the running daemon.
//
// It talks to loopback only, so it deliberately does not use netguard.Client:
// that client's allowlist covers outbound internet traffic, and 127.0.0.1 is
// not on it. The connection here never leaves the machine.
func Deliver(l paths.Layout, p Payload, budget time.Duration) error {
	info, running := daemon.ReadInfo(l)
	if !running {
		return fmt.Errorf("hookio: no daemon is running")
	}

	body, err := json.Marshal(p)
	if err != nil {
		return fmt.Errorf("hookio: encode payload: %w", err)
	}

	ctx, cancel := context.WithTimeout(context.Background(), budget)
	defer cancel()

	url := fmt.Sprintf("http://127.0.0.1:%d/hook", info.Port)
	req, err := http.NewRequestWithContext(ctx, http.MethodPost, url, bytes.NewReader(body))
	if err != nil {
		return fmt.Errorf("hookio: build request: %w", err)
	}
	req.Host = "127.0.0.1"
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("Authorization", "Bearer "+info.Token)

	client := &http.Client{Timeout: budget}
	resp, err := client.Do(req)
	if err != nil {
		return fmt.Errorf("hookio: deliver: %w", err)
	}
	defer resp.Body.Close()

	if resp.StatusCode >= 300 {
		return fmt.Errorf("hookio: daemon returned %s", resp.Status)
	}
	return nil
}
```

```go
// cmdHook is what the harness actually runs. It always exits 0.
//
// A non-zero exit from a hook is visible to the user and, under the hook
// contract, exit 2 blocks the session. team-memory is never important enough
// to interrupt someone's work, so every failure here is silent apart from a
// line on stderr.
func cmdHook(args []string, stdout, stderr io.Writer) int {
	l, err := paths.Resolve()
	if err != nil {
		fmt.Fprintf(stderr, "team-memory: %v\n", err)
		return 0
	}

	p, err := hookio.ParsePayload(os.Stdin)
	if err != nil {
		fmt.Fprintf(stderr, "team-memory: %v\n", err)
		return 0
	}
	if len(args) > 0 && p.HookEventName == "" {
		p.HookEventName = args[0]
	}

	// Start the daemon if it is not up. This is the autostart path: no
	// launchd, no systemd, no scheduled task — the first hook of the day
	// brings it up.
	if _, running := daemon.ReadInfo(l); !running {
		if err := spawnDaemon(); err != nil {
			fmt.Fprintf(stderr, "team-memory: could not start daemon: %v\n", err)
			return 0
		}
		waitForDaemon(l, hookio.Budget/2)
	}

	if err := hookio.Deliver(l, p, hookio.Budget); err != nil {
		fmt.Fprintf(stderr, "team-memory: %v\n", err)
	}
	return 0
}

// spawnDaemon starts `team-memory serve` detached from this process, so the
// hook can exit immediately without killing it.
func spawnDaemon() error {
	exe, err := os.Executable()
	if err != nil {
		return err
	}
	cmd := exec.Command(exe, "serve")
	cmd.Stdin = nil
	cmd.Stdout = nil
	cmd.Stderr = nil
	detach(cmd)
	if err := cmd.Start(); err != nil {
		return err
	}
	// Release the child so it outlives this process.
	return cmd.Process.Release()
}

// waitForDaemon polls the lock file until the daemon is up or d elapses.
func waitForDaemon(l paths.Layout, d time.Duration) {
	deadline := time.Now().Add(d)
	for time.Now().Before(deadline) {
		if _, running := daemon.ReadInfo(l); running {
			return
		}
		time.Sleep(25 * time.Millisecond)
	}
}
```

```go
// detach puts the daemon in its own process group so a Ctrl-C in the user's

func detach(cmd *exec.Cmd) {
```

```go
// Package transcript reads a harness session transcript into plain turns.
//
// Claude Code and Codex both write JSONL, one message per line, with content
// as either a bare string or an array of typed blocks. Lines that do not match
// are skipped: a transcript mixes conversation with tool records, and refusing
// the whole file over one unfamiliar line would lose the conversation.
package transcript

import (
	"bufio"
	"encoding/json"
	"errors"
	"fmt"
	"os"
	"strings"
)

// ErrUnsupportedFormat is returned when a file yields no recognisable turns
// and is not simply empty.
var ErrUnsupportedFormat = errors.New("transcript: unrecognised format")

// maxLine caps a single JSONL line. Tool results can be enormous; a line
// larger than this is skipped rather than buffered.
const maxLine = 1 << 20

// Turn is one conversational message.
type Turn struct {
	Role string
	Text string
}

// line is the subset of a transcript record we care about.
type line struct {
	Type    string `json:"type"`
	Message struct {
		Role    string          `json:"role"`
		Content json.RawMessage `json:"content"`
	} `json:"message"`
}

// block is one element of an array-form content field.
type block struct {
	Type string `json:"type"`
	Text string `json:"text"`
}

// Read returns the last max turns of the transcript at path.
func Read(path string, max int) ([]Turn, error) {
	f, err := os.Open(path)
	if err != nil {
		return nil, fmt.Errorf("transcript: open: %w", err)
	}
	defer f.Close()

	sc := bufio.NewScanner(f)
	sc.Buffer(make([]byte, 0, 64*1024), maxLine)

	var turns []Turn
	for sc.Scan() {
		raw := strings.TrimSpace(sc.Text())
		if raw == "" {
			continue
		}
		var l line
		if json.Unmarshal([]byte(raw), &l) != nil {
			continue
		}
		role := l.Message.Role
		if role == "" {
			role = l.Type
		}
		if role != "user" && role != "assistant" {
			continue
		}
		text := contentText(l.Message.Content)
		if text == "" {
			continue
		}
		turns = append(turns, Turn{Role: role, Text: text})
	}
	if err := sc.Err(); err != nil {
		return nil, fmt.Errorf("transcript: read: %w", err)
	}

	if max > 0 && len(turns) > max {
		turns = turns[len(turns)-max:]
	}
	return turns, nil
}

// contentText flattens either content form to plain text, keeping only text
// blocks. Tool calls and their results carry no conversational meaning for
// extraction and are frequently huge.
func contentText(raw json.RawMessage) string {
	if len(raw) == 0 {
		return ""
	}
	var s string
	if json.Unmarshal(raw, &s) == nil {
		return strings.TrimSpace(s)
	}
	var blocks []block
	if json.Unmarshal(raw, &blocks) != nil {
		return ""
	}
	var parts []string
	for _, b := range blocks {
		if b.Type == "text" && strings.TrimSpace(b.Text) != "" {
			parts = append(parts, strings.TrimSpace(b.Text))
		}
	}
	return strings.Join(parts, "\n")
}
```

```go
// Package redact strips credentials from text before it is written anywhere.
//
// The scan runs at capture time, not at approval time. A secret that reaches
// the staging directory has already been written to a place the user did not
// choose; catching it at approval would be too late.
package redact

import (
	"fmt"
	"regexp"
	"sort"
	"strings"
)

// Finding records one detected secret.
type Finding struct {
	Rule string
	Line int
}

// rule pairs a name with the pattern that detects it.
type rule struct {
	name string
	re   *regexp.Regexp
}

// fallbackRules covers the credential shapes that actually turn up in a
// coding session. It is deliberately conservative: a false positive costs a
// user a mangled memory, which is far cheaper than a leaked token.
var fallbackRules = []rule{
	{"github-pat", regexp.MustCompile(`gh[pousr]_[A-Za-z0-9]{36,255}`)},
	{"github-fine-grained", regexp.MustCompile(`github_pat_[A-Za-z0-9_]{60,255}`)},
	{"aws-access-key-id", regexp.MustCompile(`(?:A3T[A-Z0-9]|AKIA|ASIA|ABIA|ACCA)[A-Z0-9]{16}`)},
	{"slack-token", regexp.MustCompile(`xox[baprs]-[A-Za-z0-9-]{10,}`)},
	{"anthropic-key", regexp.MustCompile(`sk-ant-[A-Za-z0-9_-]{20,}`)},
	{"openai-key", regexp.MustCompile(`sk-[A-Za-z0-9]{32,}`)},
	{"google-api-key", regexp.MustCompile(`AIza[A-Za-z0-9_-]{35}`)},
	{"private-key", regexp.MustCompile(`(?s)-----BEGIN[ A-Z]*PRIVATE KEY-----.*?-----END[ A-Z]*PRIVATE KEY-----`)},
	{"jwt", regexp.MustCompile(`eyJ[A-Za-z0-9_-]{10,}\.eyJ[A-Za-z0-9_-]{10,}\.[A-Za-z0-9_-]{10,}`)},
	{"basic-auth-url", regexp.MustCompile(`[a-z][a-z0-9+.-]*://[^/\s:@]+:[^/\s:@]+@[^\s]+`)},
}

// alreadyRedacted matches our own marker so Clean is idempotent.
var alreadyRedacted = regexp.MustCompile(`\[REDACTED:[a-z0-9-]+\]`)

// Scan reports every secret found in text, ordered by position.
func Scan(text string) []Finding {
	var out []Finding
	for _, r := range fallbackRules {
		for _, loc := range r.re.FindAllStringIndex(text, -1) {
			out = append(out, Finding{
				Rule: r.name,
				Line: 1 + strings.Count(text[:loc[0]], "\n"),
			})
		}
	}
	sort.Slice(out, func(i, j int) bool {
		if out[i].Line != out[j].Line {
			return out[i].Line < out[j].Line
		}
		return out[i].Rule < out[j].Rule
	})
	return out
}

// Clean replaces every secret with a marker naming the rule that caught it,
// and returns what it found. Applying Clean to its own output changes nothing.
func Clean(text string) (string, []Finding) {
	findings := Scan(text)
	out := text
	for _, r := range fallbackRules {
		rr := r
		out = rr.re.ReplaceAllStringFunc(out, func(match string) string {
			if alreadyRedacted.MatchString(match) {
				return match
			}
			return fmt.Sprintf("[REDACTED:%s]", rr.name)
		})
	}
	return out, findings
}
```

```go
// Package extract turns a conversation into candidate memories using the
// coding agent the user already has installed and authenticated.
//
// team-memory holds no API key and makes no LLM API call of its own. It runs
// `claude -p` or `codex exec` as a subprocess, so whatever authentication the
// user has arranged is the authentication used, and nothing about the
// conversation goes anywhere the user's own agent would not already send it.
package extract

import (
	"bytes"
	"context"
	"fmt"
	"os/exec"
	"strings"
	"time"
)

// Timeout bounds one extraction. Extraction is background work; a run that
// takes longer than this is abandoned rather than left to accumulate.
const Timeout = 90 * time.Second

// Runner is a local coding agent that can answer a prompt.
type Runner interface {
	// Name is the agent's name, e.g. "claude".
	Name() string
	// Available reports whether the binary is on PATH.
	Available() bool
	// Run answers prompt and returns the agent's stdout.
	Run(ctx context.Context, prompt string) (string, error)
}

// cliRunner runs a coding agent in non-interactive mode.
type cliRunner struct {
	name string
	bin  string
	args []string
}

func (c cliRunner) Name() string { return c.name }

func (c cliRunner) Available() bool {
	_, err := exec.LookPath(c.bin)
	return err == nil
}

// Run passes the prompt on stdin rather than as an argument: prompts routinely
// exceed the platform's command-line length limit.
func (c cliRunner) Run(ctx context.Context, prompt string) (string, error) {
	ctx, cancel := context.WithTimeout(ctx, Timeout)
	defer cancel()

	cmd := exec.CommandContext(ctx, c.bin, c.args...)
	cmd.Stdin = strings.NewReader(prompt)

	var out, errBuf bytes.Buffer
	cmd.Stdout = &out
	cmd.Stderr = &errBuf

	if err := cmd.Run(); err != nil {
		return "", fmt.Errorf("extract: %s failed: %w: %s",
			c.name, err, strings.TrimSpace(errBuf.String()))
	}
	return out.String(), nil
}

// runners are the agents team-memory knows how to drive.
//
// Both read the prompt from stdin. `claude -p` prints its answer and exits;
// `codex exec` does the same.
var runners = []cliRunner{
	{name: "claude", bin: "claude", args: []string{"-p"}},
	{name: "codex", bin: "codex", args: []string{"exec"}},
}

// Detect returns the agents actually installed on this machine.
func Detect() []Runner {
	var out []Runner
	for _, r := range runners {
		if r.Available() {
			out = append(out, r)
		}
	}
	return out
}
```

```go
package extract

import (
	"context"
	"encoding/json"
	"errors"
	"fmt"
	"strings"

	"github.com/AndrewSkea/team-memory/mcp/redact"
	"github.com/AndrewSkea/team-memory/mcp/transcript"
)

// maxTurns bounds how much conversation is sent to the agent. The end of a
// session holds the conclusions; the beginning holds the flailing.
const maxTurns = 40

// maxTurnChars truncates a single very long turn.
const maxTurnChars = 4000

// Candidate is one proposed memory, before a human has seen it.
type Candidate struct {
	Title      string   `json:"title"`
	Body       string   `json:"body"`
	Scope      string   `json:"scope"`
	Tags       []string `json:"tags"`
	Confidence float64  `json:"confidence"`
}

const promptHeader = `You are reviewing a finished coding session to find facts worth remembering for the team.

Save a memory only for something that will still be true and useful next month: a decision and why it was made, a convention the team follows, where something lives, a constraint that is not obvious from the code.

Do NOT save: anything already obvious from reading the code, transient debugging steps, what one person happened to be doing today, or restatements of the task.

Answer with a JSON array and nothing else. Each element:
  {"title": short title, "body": one or two full sentences, "scope": "team" or "personal", "tags": [strings], "confidence": 0.0 to 1.0}

Use "personal" only when the fact is about one individual's own setup or preference. Default to "team".

If there are no memories worth saving, answer with an empty array: []

Conversation:
`

// BuildPrompt renders the extraction prompt.
//
// The conversation is redacted before it is written into the prompt: the
// agent is a subprocess, but its input still reaches a model, and a secret
// should not.
func BuildPrompt(turns []transcript.Turn) string {
	if len(turns) > maxTurns {
		turns = turns[len(turns)-maxTurns:]
	}

	var b strings.Builder
	b.WriteString(promptHeader)
	for _, t := range turns {
		text := t.Text
		if len(text) > maxTurnChars {
			text = text[:maxTurnChars] + " […truncated]"
		}
		clean, _ := redact.Clean(text)
		fmt.Fprintf(&b, "\n%s: %s\n", t.Role, clean)
	}
	return b.String()
}

// ParseCandidates reads the agent's answer. Agents preface their output, so
// the JSON array is located rather than assumed to be the whole response.
func ParseCandidates(raw string) ([]Candidate, error) {
	body, ok := findJSONArray(raw)
	if !ok {
		return nil, errors.New("extract: agent output contained no JSON array")
	}

	var all []Candidate
	if err := json.Unmarshal([]byte(body), &all); err != nil {
		return nil, fmt.Errorf("extract: decode agent output: %w", err)
	}

	out := make([]Candidate, 0, len(all))
	for _, c := range all {
		if strings.TrimSpace(c.Body) == "" {
			continue
		}
		if strings.TrimSpace(c.Title) == "" {
			c.Title = firstSentence(c.Body)
		}
		if !strings.EqualFold(c.Scope, "personal") {
			c.Scope = "team"
		} else {
			c.Scope = "personal"
		}
		out = append(out, c)
	}
	return out, nil
}

// findJSONArray returns the outermost bracketed span of raw.
func findJSONArray(raw string) (string, bool) {
	start := strings.Index(raw, "[")
	end := strings.LastIndex(raw, "]")
	if start < 0 || end < start {
		return "", false
	}
	return raw[start : end+1], true
}

func firstSentence(s string) string {
	s = strings.TrimSpace(s)
	if i := strings.IndexAny(s, ".!?\n"); i > 0 {
		s = s[:i]
	}
	if len(s) > 80 {
		s = s[:80]
	}
	return s
}

// Extract runs one extraction end to end.
func Extract(ctx context.Context, r Runner, turns []transcript.Turn) ([]Candidate, error) {
	if len(turns) == 0 {
		// Never spend the user's tokens on an empty conversation.
		return nil, nil
	}

	raw, err := r.Run(ctx, BuildPrompt(turns))
	if err != nil {

		cands[i].Title, _ = redact.Clean(cands[i].Title)
	}
```

```go
// Package capture connects a harness hook to the staging queue.
//
// The HTTP handler answers 202 and does the work in the background: a hook
// that waits for an LLM call is a hook the user disables within a week.
package capture

import (
	"context"
	"log"
	"net/http"
	"sync"
	"time"

	"github.com/AndrewSkea/team-memory/mcp/extract"
	"github.com/AndrewSkea/team-memory/mcp/hookio"
	"github.com/AndrewSkea/team-memory/mcp/memory"
	"github.com/AndrewSkea/team-memory/mcp/staging"
	"github.com/AndrewSkea/team-memory/mcp/transcript"
)

// Memory levels. This is the user's privacy control and it is a floor, not a
// ceiling: no configuration file can raise a user above the level they chose.
const (
	LevelOff    = "off"
	LevelReview = "review"
	LevelAuto   = "auto"
)

// maxTurns is how much of the transcript's tail is considered.
const maxTurns = 60

// Config is the capture behaviour.
type Config struct {
	// Level is one of LevelOff, LevelReview, LevelAuto. An unrecognised value
	// is treated as LevelOff: an unreadable setting must fail closed.
	Level string
}

// Capturer processes hook events.
type Capturer struct {
	staging *staging.Area
	runner  extract.Runner
	cfg     Config

	wg sync.WaitGroup
}

// New builds a Capturer. runner may be nil, in which case extraction is
// skipped and hook events are accepted and discarded.
func New(st *staging.Area, r extract.Runner, cfg Config) *Capturer {
	return &Capturer{staging: st, runner: r, cfg: cfg}
}

// Handler serves POST /hook. It always answers before doing any work.
func (c *Capturer) Handler() http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if r.Method != http.MethodPost {
			w.Header().Set("Allow", http.MethodPost)
			http.Error(w, "method not allowed", http.StatusMethodNotAllowed)
			return
		}

		p, err := hookio.ParsePayload(r.Body)
		if err != nil {
			http.Error(w, err.Error(), http.StatusBadRequest)
			return
		}

		w.WriteHeader(http.StatusAccepted)

		c.wg.Add(1)
		go func() {
			defer c.wg.Done()
			// Detached from the request context, which is cancelled the moment
			// the 202 is written.
			ctx, cancel := context.WithTimeout(context.Background(), 5*time.Minute)
			defer cancel()
			if _, err := c.Process(ctx, p); err != nil {
				log.Printf("team-memory: capture %s: %v", p.SessionID, err)
			}
		}()
	})
}

// Wait blocks until background work finishes. Test helper.
func (c *Capturer) Wait() { c.wg.Wait() }

// Process handles one hook event and reports how many memories were staged.
func (c *Capturer) Process(ctx context.Context, p hookio.Payload) (int, error) {
	if c.cfg.Level != LevelReview && c.cfg.Level != LevelAuto {
		// off, or an unreadable value. Read nothing, write nothing.
		return 0, nil
	}
	if c.runner == nil || p.TranscriptPath == "" {
		return 0, nil
	}

	turns, err := transcript.Read(p.TranscriptPath, maxTurns)
	if err != nil {
		// A transcript that is missing or mid-write is ordinary, not an error
		// worth surfacing to a user who is finishing their session.
		return 0, nil
	}
	if len(turns) == 0 {
		return 0, nil
	}

	cands, err := extract.Extract(ctx, c.runner, turns)
	if err != nil {
		return 0, err
	}

	staged := 0
	for _, cand := range cands {
		m := memory.Memory{
			Created:       time.Now().UTC().Truncate(time.Second),
			Author:        author(),
			Scope:         memory.Scope(cand.Scope),
			Tags:          cand.Tags,
			SourceSession: p.SessionID,
			Confidence:    cand.Confidence,
			Slug:          cand.Title,
			Body:          cand.Body,
		}
		m.ID = memory.ComputeID(m)
		if err := c.staging.Add(m); err != nil {
			return staged, err
		}
		staged++
	}
	return staged, nil
}
```

```go
// remoteName is the single remote team-memory manages.
const remoteName = "origin"

// ErrNoRemote is returned when a push is attempted with no remote configured.
var ErrNoRemote = errors.New("store: no remote configured")

// Remote returns the configured remote URL.
func (s *Store) Remote() (string, bool) {
	rem, err := s.repo.Remote(remoteName)
	if err != nil {
		return "", false
	}
	urls := rem.Config().URLs
	if len(urls) == 0 {
		return "", false
	}
	return urls[0], true
}

// SetRemote points the store at a remote, replacing any existing one.
func (s *Store) SetRemote(url string) error {
	if _, err := s.repo.Remote(remoteName); err == nil {
		if err := s.repo.DeleteRemote(remoteName); err != nil {
			return fmt.Errorf("store: replace remote: %w", err)
		}
	}
	_, err := s.repo.CreateRemote(&config.RemoteConfig{
		Name: remoteName,
		URLs: []string{url},
	})
	if err != nil {
		return fmt.Errorf("store: set remote: %w", err)
	}
	return nil
}

// Push publishes the current branch.
//
// It is never a force push. A rejected push means somebody else published
// first; the answer is Sync then Push again, not rewriting their history.
func (s *Store) Push(ctx context.Context) error {
	if _, ok := s.Remote(); !ok {
		return ErrNoRemote
	}

	head, err := s.repo.Head()
	if err != nil {
		// No commits yet: nothing to publish, and that is not a failure.
		return nil
	}
	branch := head.Name()

	auth, err := s.auth()
	if err != nil {
		return err
	}

	err = s.repo.PushContext(ctx, &git.PushOptions{
		RemoteName: remoteName,
		RefSpecs: []gitconfig.RefSpec{
			gitconfig.RefSpec(branch + ":" + branch),
		},
		Auth:  auth,
		Force: false,
	})
	if errors.Is(err, git.NoErrAlreadyUpToDate) {
		return nil
	}
	if err != nil {
		return fmt.Errorf("store: push: %w", err)
	}
	return nil
}
```

```go
// approveRequest is the body of POST /api/approve. Every field except id is
// an optional edit applied before the memory is committed.
type approveRequest struct {
	ID    string   `json:"id"`
	Title string   `json:"title"`
	Body  string   `json:"body"`
	Scope string   `json:"scope"`
	Tags  []string `json:"tags"`
}

// approve is the only code path in team-memory that writes to the git
// repository. Keeping it alone is the whole privacy guarantee, and
// TestApproveIsTheOnlyCallerOfStorePut enforces it.
//
// Take is non-destructive: it claims the pending file and leaves it on disk.
// This handler owns that claim until it calls Done (committed) or Abort
// (refused). See the note below on why every exit path must do one or
// the other.
func (a *API) approve(w http.ResponseWriter, r *http.Request) {
	var req approveRequest
	if err := json.NewDecoder(r.Body).Decode(&req); err != nil || req.ID == "" {
		writeError(w, http.StatusBadRequest, "body must be an object with an id")
		return
	}

	m, err := a.staging.Take(req.ID)
	if errors.Is(err, os.ErrNotExist) {
		writeError(w, http.StatusNotFound, "no pending memory has id "+req.ID)
		return
	}
	if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}

	// From here to the Put below, every exit path must call Abort. A claim
	// that is neither Done nor Aborted hides the memory from the review queue
	// until it goes stale, so a reviewer watches their approval disappear and
	// come back a minute later.

	// Apply the reviewer's edits.
	if strings.TrimSpace(req.Body) != "" {
		m.Body = strings.TrimSpace(req.Body)
	}
	if strings.TrimSpace(req.Title) != "" {
		m.Slug = strings.TrimSpace(req.Title)
	}
	if req.Scope != "" {
		m.Scope = memory.Scope(req.Scope)
	}
	if req.Tags != nil {
		m.Tags = req.Tags
	}

	// Redact once more. A reviewer can paste a credential into the edit box,
	// and this is the last moment before it becomes permanent.
	m.Body, _ = redact.Clean(m.Body)
	m.Slug, _ = redact.Clean(m.Slug)

	if _, err := a.store.Put(m, "memory: approve "+m.ID); err != nil {
		// Take left the pending file in place, held by a claim. Release it so
		// the memory returns to the queue instead of vanishing: the store, not
		// staging, is the commit point, and the store just refused.
		if aerr := a.staging.Abort(req.ID); aerr != nil {
			log.Printf("team-memory: abort claim %s: %v", req.ID, aerr)
		}
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}

	// Committed. Only now may the pending file go.
	if err := a.staging.Done(req.ID); err != nil {
		log.Printf("team-memory: clear pending %s after approve: %v", req.ID, err)
	}

	if err := a.reindex(); err != nil {
		// A stale index is a degraded search, not a failed approval. The
		// memory is committed; say so.
		log.Printf("team-memory: reindex after approve: %v", err)
	}

	if a.push {
		go func(id string) {
			if err := a.store.Push(context.Background()); err != nil &&
				!errors.Is(err, store.ErrNoRemote) {
				log.Printf("team-memory: push after approving %s: %v", id, err)
			}
		}(m.ID)
	}

	writeJSON(w, http.StatusOK, map[string]any{"id": m.ID, "status": "approved"})
}
```

```go
// forget removes a committed memory with an ordinary commit.
//
// The response is deliberately honest: if the memory was ever pushed, its text
// remains in git history on every clone, and removing the file does not
// unpublish it.
func (a *API) forget(w http.ResponseWriter, r *http.Request) {
	req, ok := decodeID(r)
	if !ok {
		writeError(w, http.StatusBadRequest, "body must be an object with an id")
		return
	}

	all, err := a.store.All()
	if err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	var found *memory.Memory
	for i := range all {
		if all[i].ID == req.ID {
			found = &all[i]
			break
		}
	}
	if found == nil {
		writeError(w, http.StatusNotFound, "no memory has id "+req.ID)
		return
	}

	if err := a.store.Remove(*found, "memory: forget "+req.ID); err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}
	if err := a.reindex(); err != nil {
		writeError(w, http.StatusInternalServerError, err.Error())
		return
	}

	writeJSON(w, http.StatusOK, map[string]any{
		"id":     req.ID,
		"status": "forgotten",
		"note": "Removed going forward. If this was already pushed, the text stays in git " +
			"history on every clone. If it contained a credential, rotate the credential — " +
			"rewriting history is not a substitute.",
	})
}

// reindex rebuilds the search index from the repository.
func (a *API) reindex() error {
	all, err := a.store.All()
	if err != nil {
		return err
	}
	return a.index.Rebuild(all)
}

func (a *API) writeStagingError(w http.ResponseWriter, err error) {
	if errors.Is(err, os.ErrNotExist) {
		writeError(w, http.StatusNotFound, err.Error())
		return
	}
	writeError(w, http.StatusInternalServerError, err.Error())
}

type item struct {

	Title         string   `json:"title"`
	Body          string   `json:"body"`
	Scope         string   `json:"scope"`
	Author        string   `json:"author"`
```

```go
// Package install wires team-memory into a coding harness.
//
// The two harnesses keep configuration in different formats, so the install
// differs per harness rather than being forced into one shape. Both installs
// merge into whatever is already there and take a timestamped backup first: a
// tool that clobbers a user's editor configuration does not get a second
// chance.
package install

import (
	"encoding/json"
	"fmt"
	"os"
	"path/filepath"
	"strings"
	"time"
)

// Report describes what an install did.
type Report struct {
	Path    string
	Changed bool
	Backup  string
	Notes   []string
}

// Target is one harness team-memory can install into.
type Target interface {
	Name() string
	ConfigPath() (string, error)
	Install(exe string) (Report, error)
}

// events are the hook events team-memory subscribes to. Both fire when a
// conversation's useful content is complete, which is when extraction is worth
// the tokens.
var events = []string{"SessionEnd", "PreCompact"}

// Targets returns every harness this build knows how to install into.
func Targets() []Target {
	return []Target{claudeTarget{}, codexTarget{}}
}

// Find looks up a target by name.
func Find(name string) (Target, bool) {
	for _, t := range Targets() {
		if strings.EqualFold(t.Name(), name) {
			return t, true
		}
	}
	return nil, false
}

// homeDir resolves the user's home directory, honouring the environment so
// tests can redirect it.
func homeDir() (string, error) {
	if h := os.Getenv("HOME"); h != "" {
		return h, nil
	}
	if h := os.Getenv("USERPROFILE"); h != "" {
		return h, nil
	}
	h, err := os.UserHomeDir()
	if err != nil {
		return "", fmt.Errorf("install: locate home directory: %w", err)
	}
	return h, nil
}

// backup copies path to a timestamped sibling. It returns "" when there was
// nothing to back up.
func backup(path string) (string, error) {
	data, err := os.ReadFile(path)
	if os.IsNotExist(err) {
		return "", nil
	}
	if err != nil {
		return "", fmt.Errorf("install: read %s: %w", path, err)
	}
	dst := fmt.Sprintf("%s.backup-%s", path, time.Now().UTC().Format("20060102-150405"))
	if err := os.WriteFile(dst, data, 0o600); err != nil {
		return "", fmt.Errorf("install: write backup: %w", err)
	}
	return dst, nil
}

// writeFile creates parent directories and writes atomically via a temporary
// file, so an interrupted install never leaves a truncated config.
func writeFile(path string, data []byte) error {
	if err := os.MkdirAll(filepath.Dir(path), 0o755); err != nil {
		return fmt.Errorf("install: create directory: %w", err)
	}
	tmp := path + ".tmp"
	if err := os.WriteFile(tmp, data, 0o600); err != nil {
		return fmt.Errorf("install: write %s: %w", tmp, err)
	}
	if err := os.Rename(tmp, path); err != nil {
		return fmt.Errorf("install: replace %s: %w", path, err)
	}
	return nil
}

// hookCommand is what a harness runs for one event.
func hookCommand(exe, event string) string {
	return fmt.Sprintf("%q hook %s", exe, event)
}
```

```go
type claudeTarget struct{}

func (claudeTarget) Name() string { return "claude" }

func (claudeTarget) ConfigPath() (string, error) {
	home, err := homeDir()
	if err != nil {
		return "", err
	}
	return filepath.Join(home, ".claude", "settings.json"), nil
}

// Install merges team-memory's hooks and MCP server into settings.json.
//
// The file is read as a generic map rather than a typed struct so that
// settings this build does not know about survive the round trip.
func (c claudeTarget) Install(exe string) (Report, error) {
	path, err := c.ConfigPath()
	if err != nil {
		return Report{}, err
	}

	settings := map[string]any{}
	if data, err := os.ReadFile(path); err == nil && len(data) > 0 {
		if err := json.Unmarshal(data, &settings); err != nil {
			return Report{}, fmt.Errorf(
				"install: %s is not valid JSON; fix or move it, then run install again: %w", path, err)
		}
	} else if err != nil && !os.IsNotExist(err) {
		return Report{}, fmt.Errorf("install: read %s: %w", path, err)
	}

	bak, err := backup(path)
	if err != nil {
		return Report{}, err
	}

	hooks, _ := settings["hooks"].(map[string]any)
	if hooks == nil {
		hooks = map[string]any{}
	}
	for _, event := range events {
		hooks[event] = mergeHookEvent(hooks[event], exe, event)
	}
	settings["hooks"] = hooks

	servers, _ := settings["mcpServers"].(map[string]any)
	if servers == nil {
		servers = map[string]any{}
	}
	servers["team-memory"] = map[string]any{
		"type":           "http",
		"url":            "http://127.0.0.1:7373/mcp",
		"headersHelper":  fmt.Sprintf("%q mcp-headers", exe),
	}
	settings["mcpServers"] = servers

	out, err := json.MarshalIndent(settings, "", "  ")
	if err != nil {
		return Report{}, fmt.Errorf("install: encode settings: %w", err)
	}
	if err := writeFile(path, append(out, '\n')); err != nil {
		return Report{}, err
	}

	return Report{
		Path:    path,
		Changed: true,
		Backup:  bak,
		Notes: []string{
			"Hooks registered for " + fmt.Sprint(events) + ".",
			"Restart Claude Code for the change to take effect.",
		},
	}, nil
}

// mergeHookEvent adds team-memory's command to one event's matcher list
// without disturbing the user's own hooks, and without adding a duplicate on
// a second install.
func mergeHookEvent(existing any, exe, event string) any {
	want := hookCommand(exe, event)

	matchers, _ := existing.([]any)
	for _, raw := range matchers {
		matcher, _ := raw.(map[string]any)
		inner, _ := matcher["hooks"].([]any)
		for _, h := range inner {
			hook, _ := h.(map[string]any)
			if cmd, _ := hook["command"].(string); cmd == want {
				return matchers // already installed
			}
		}
	}

	return append(matchers, map[string]any{
		"hooks": []any{
			map[string]any{
				"type":    "command",
				"command": want,
				"timeout": 5,
			},
		},
	})
}
```

```go
	"fmt"
	"os"
	"path/filepath"
	"strings"
)

type codexTarget struct{}

func (codexTarget) Name() string { return "codex" }

func (codexTarget) ConfigPath() (string, error) {

	if err != nil {
		return "", err
	}
	return filepath.Join(home, ".codex", "config.toml"), nil

// managedStart and managedEnd delimit the block team-memory owns.
//
// Codex's config is TOML with comments the user cares about. Rather than
// parse and re-emit it — which would lose their comments and reorder their
// keys — the install appends a clearly marked block and replaces that block
// on a re-install.
const (
	managedStart = "# >>> team-memory (managed) >>>"
	managedEnd   = "# <<< team-memory (managed) <<<"
)

func (c codexTarget) Install(exe string) (Report, error) {
	path, err := c.ConfigPath()
	if err != nil {
		return Report{}, err
	}

	current := ""
	if data, err := os.ReadFile(path); err == nil {
		current = string(data)
	} else if !os.IsNotExist(err) {
		return Report{}, fmt.Errorf("install: read %s: %w", path, err)
	}

	bak, err := backup(path)
	if err != nil {
		return Report{}, err
	}

	updated := replaceManagedBlock(current, c.block(exe))
	if err := writeFile(path, []byte(updated)); err != nil {
		return Report{}, err
	}

	return Report{
		Path:    path,
		Changed: true,
		Backup:  bak,
		Notes: []string{
			"Configuration added between the team-memory markers; edit outside them freely.",
			"Restart Codex for the change to take effect.",
		},
	}, nil
}

// block renders the TOML team-memory manages.
func (codexTarget) block(exe string) string {
	var b strings.Builder
	b.WriteString(managedStart + "\n")
	b.WriteString("[mcp_servers.team-memory]\n")
	b.WriteString("url = \"http://127.0.0.1:7373/mcp\"\n")
	b.WriteString(fmt.Sprintf("http_headers_helper = [%q, \"mcp-headers\"]\n\n", exe))
	for _, event := range events {
		b.WriteString(fmt.Sprintf("[[hooks.%s]]\n", event))
		b.WriteString(fmt.Sprintf("command = [%q, \"hook\", %q]\n", exe, event))
		b.WriteString("timeout_ms = 5000\n\n")
	}
	b.WriteString(managedEnd + "\n")
	return b.String()
}

// replaceManagedBlock swaps our block for a new one, or appends it if this is
// the first install. Everything outside the markers is untouched.
func replaceManagedBlock(current, block string) string {
	start := strings.Index(current, managedStart)
	end := strings.Index(current, managedEnd)
	if start >= 0 && end > start {
		end += len(managedEnd)
		for end < len(current) && current[end] == '\n' {
			end++
		}
		return current[:start] + block + current[end:]
	}
	if current != "" && !strings.HasSuffix(current, "\n") {
		current += "\n"
	}
	if current != "" {
		current += "\n"
	}
	return current + block
}
```

```go
func cmdInstall(args []string, stdout, stderr io.Writer) int {
	if len(args) == 0 {
		fmt.Fprintln(stderr, "team-memory: which agent? Try: team-memory install claude")
		var names []string
		for _, t := range install.Targets() {
			names = append(names, t.Name())
		}
		fmt.Fprintf(stderr, "Known agents: %s\n", strings.Join(names, ", "))
		return 2
	}

	target, ok := install.Find(args[0])
	if !ok {
		fmt.Fprintf(stderr, "team-memory: no installer for %q\n", args[0])
		return 2
	}

	exe, err := os.Executable()
	if err != nil {
		fmt.Fprintf(stderr, "team-memory: locate this binary: %v\n", err)
		return 1
	}

	rep, err := target.Install(exe)
	if err != nil {
		fmt.Fprintf(stderr, "team-memory: %v\n", err)
		return 1
	}

	fmt.Fprintf(stdout, "Installed into %s\n", rep.Path)
	if rep.Backup != "" {
		fmt.Fprintf(stdout, "Previous version saved as %s\n", rep.Backup)
	}
	for _, n := range rep.Notes {
		fmt.Fprintf(stdout, "  %s\n", n)
	}
	fmt.Fprintln(stdout, "\nMemory saving is OFF until you choose a level. Run: team-memory serve")
	return 0
}

// cmdMCPHeaders prints the Authorization header the harness should send, and
// starts the daemon if it is not already up. Harnesses call this before each
// MCP connection, which makes it a second autostart path.
func cmdMCPHeaders(stdout, stderr io.Writer) int {
	l, err := paths.Resolve()
	if err != nil {
		fmt.Fprintf(stderr, "team-memory: %v\n", err)
		return 1
	}
	if _, running := daemon.ReadInfo(l); !running {
		if err := spawnDaemon(); err != nil {
			fmt.Fprintf(stderr, "team-memory: %v\n", err)
			return 1
		}
		waitForDaemon(l, 3*time.Second)
	}
	info, running := daemon.ReadInfo(l)
	if !running {
		fmt.Fprintln(stderr, "team-memory: daemon did not start")
		return 1
	}
	fmt.Fprintf(stdout, "{\"Authorization\":\"Bearer %s\"}\n", info.Token)
	return 0
}
```
